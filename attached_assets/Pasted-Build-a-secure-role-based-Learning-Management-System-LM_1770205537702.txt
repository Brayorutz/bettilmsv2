Build a secure, role-based Learning Management System (LMS) specifically branded for Belgut Technical Training Institute (BeTTI) with a world-class, clean, and intuitive UI using a consistent Green, Blue, and Gold color system across all interfaces. Green must represent academic progress, success states, confirmations, and active selections; Blue must be used for primary navigation, headers, links, and system trust elements; Gold must be applied sparingly for highlights, badges, deadlines, progress indicators, and important alerts. The System Admin creates lecturers by assigning full name, staff number, department, course(s), and a temporary password, supporting lecturers who teach across multiple departments and courses at BeTTI. Lecturers log in and create units under their assigned courses, then enroll students into specific units using a strict admission number format (e.g., SCM/6155/25S), student full name, and temporary password. If a student admission number already exists in the system, the LMS must automatically detect it and display a confirmation prompt such as “This student is already registered in Unit X. Do you want to add them to this unit?” to prevent duplicate registrations while allowing a single student to be bound to multiple units taught by different lecturers. Students log in using their admission number, are forced to change their password on first login, and see only their assigned units on a personalized dashboard. Lecturers upload teaching materials per unit (PDFs, videos, scanned notes, assignments, and Q&A tasks) with a clearly styled instruction box visible to students. Upon upload, students receive real-time dashboard notifications and visual indicators. Lecturers may optionally set deadlines; once a deadline passes, students can view but cannot access the content, with clear gold-accented warning messages, while approaching deadlines trigger reminder alerts. The UI must be fully responsive for mobile and desktop, use card-based layouts for units and materials, include a sidebar for navigation, a top navbar for profile and logout, smooth animations, toast notifications, progress indicators, and maintain strict visual consistency with BeTTI branding using the Green–Blue–Gold theme across the entire system.
